# Kaggle Dataset

## Dataset Name
Potholes-Detection-YOLOv8

## Dataset Details
- Training Images: 1,581
- Validation Images: 396
- Classes: Pothole
- Annotation Format: YOLO
- License: CC0

## Reported Reference Results

A publicly available Kaggle notebook using this dataset reported the following validation results:

- mAP@50: 78.90%
- mAP@50-95: 52.26%
- Precision: 81.21%
- Recall: 69.92%
- F1 Score: 75.14%

These are results reported by an external Kaggle notebook and are not the final results of our project.

## Why It Was Selected

- Specifically designed for pothole detection.
- Provides object-detection annotations in YOLO format.
- Compatible with YOLO-based object detection models.
- Contains a pothole-only class.
- Suitable for the current project requirements.

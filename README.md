# SKIT-CSE-2023-2027-53
AI-powered pothole detection system using YOLOv8 and smartphone-recorded road video with synced GPS. Detects potholes, geotags them, computes a road-condition score per segment, and visualizes results on an interactive Streamlit + Folium dashboard.
# Dataset Analysis and Model Training
